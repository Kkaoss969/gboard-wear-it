# Gboard per Wear OS — versione per Huawei Watch 4

Gboard per Wear OS (Google) modificata in modo non ufficiale per funzionare sullo Huawei Watch 4, che non ha i Google
Play Services: legge i dizionari da una cartella dell'orologio, non mostra l'avviso «In attesa del download della lingua»
e ha la vibrazione dei tasti spenta di base. Si installa da Gateway Assistant (Store di prova), che scarica i dizionari
delle lingue scelte direttamente dai server di Google.

Gboard è un'app di Google: questo repository non è affiliato a Google. Su richiesta del titolare dei diritti il file
viene tolto.
